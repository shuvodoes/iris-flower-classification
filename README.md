# iris-flower-classification
Iris flower classification using Random Forest to predict species.

🌸 Iris Flower Classification 
Welcome to the Iris Flower Classification project! This is a machine learning model built to classify Iris flowers into one of three species based on their petal and sepal measurements.

🌼 Project Overview
In this project, we use a Random Forest classifier to predict the species of an Iris flower from the famous Iris dataset. The model uses the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The three species in the dataset are:

1. Setosa
2. Versicolor
3. Virginica


💡 Model Performance
The Random Forest model performs remarkably well, achieving 100% accuracy on the Iris dataset!

Classification Report:
Here’s how the model performs in detail:

Setosa: Perfectly predicted with precision, recall, and F1-score all being 1.00.

Versicolor: Same as Setosa, with 100% accuracy across the board.

Virginica: Again, flawless with perfect metrics.
